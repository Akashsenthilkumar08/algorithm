# Analyze LCS for Two Large Sequences

## 📌 Project Overview

**Analyze LCS for Two Large Sequences** is a mini project that implements and visualizes the **Longest Common Subsequence (LCS)** algorithm for comparing two sequences.

The project demonstrates how Dynamic Programming can be used to identify the longest sequence of elements that appears in the same relative order in two different sequences, without requiring the elements to be consecutive.

This project is designed to help understand the practical application of **Dynamic Programming, sequence comparison, matrix-based computation, and algorithm visualization**.

---

## 🎯 Objectives

- Understand the concept of the Longest Common Subsequence.
- Implement LCS using Dynamic Programming.
- Compare two sequences efficiently.
- Calculate the length of the longest common subsequence.
- Display the actual LCS between the sequences.
- Visualize the Dynamic Programming matrix.
- Understand how the algorithm reaches the final result.
- Analyze the time and space complexity of the algorithm.

---

## 🧠 What is LCS?

The **Longest Common Subsequence (LCS)** is the longest sequence that can be obtained from two sequences while maintaining the original order of elements.

The elements do **not** need to be adjacent.
